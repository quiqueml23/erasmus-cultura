# erasmus

Proyecto personal para organizar mi estancia Erasmus 2026/27. Cada iniciativa vive en su propia sección para poder ampliarla sin mezclar código ni datos.

## Secciones

### Calendario cultural de Košice
Recopila eventos culturales de Košice y publica un calendario iCalendar para suscribirse desde el iPhone.

- [Abrir la web del calendario](https://quiqueml23.github.io/erasmus-cultura/)
- [Ver la sección y su documentación](kosice-cultural-calendar/README.md)
- [Código, datos y generador](kosice-cultural-calendar/)

La web pública se publica desde la carpeta `kosice-cultural-calendar/` mediante GitHub Pages. El feed de suscripción está en [kosice_cultura.ics](https://quiqueml23.github.io/erasmus-cultura/kosice_cultura.ics).

## Desarrollo

La carpeta `.github/workflows/` contiene la publicación del sitio. Para añadir una nueva iniciativa, crea otra carpeta de primer nivel y documenta aquí el acceso.
